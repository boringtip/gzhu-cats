# 广大猫猫图鉴 · GZHU Campus Cats

一个单文件的校园猫图鉴网页。手机和电脑都能用：手机左右滑动，电脑点箭头、点屏幕、滚轮、键盘都行。

```
gzhu-cats/
├── index.html      网页本体（样式和脚本都在里面）
├── assets/
│   ├── c01~c19.jpg   19 张照片（900px 宽）
│   ├── thumbs/       名录用的缩略图（240px），缺了会自动退回大图
│   └── tip.jpg       赞赏码
└── README.md
```

页面顺序（24 页）：

```
封面 → 名录 → 17 只猫 → 「名录还没写完」→ 赞赏码 → 幸运抽奖 → 救助总则 → 守距相伴
```

名录放在最前面，进来点一只就能跳过去。最后两页是猫协的救助守则，内容整理自 Meow Meow Guardians 的两张图，重新排版过。

## 一、日常改内容，只动两个地方

打开 `index.html`，搜 `const SITE` 和 `const CATS`。

### 1. 站点文字

```js
const SITE = {
  school : "广州大学",
  title  : ["广大猫猫", "图鉴"],   // 封面两行；第二行是砖红色
  en     : "GZHU CAMPUS CATS",
  kicker : "广州大学 · 校园猫档案",
  intro  : "一份还在生长的名录……",
  vol    : "第 01 辑",
  season : "2026 秋",
  tipImg   : "assets/tip.jpg",
  tipLine1 : "制作不易，感谢支持呀 ฅ(˘ω˘)ฅ♡",
  tipLine2 : "有问题直接留言；……",
  moreTitle : "名录还没写完",
  moreText  : "还有猫没上镜。……",
  shareLine : "欢迎转发给爱猫的同学，也欢迎随手支持 ♡",   // 封面上那个小标签
  luckyKicker : "LUCKY CAT",
  luckyTitle  : "抽一只<br>你的幸运猫猫",                 // 可以写 <br> 换行
  luckySub    : "全部猫猫都在签筒里，抽到的那只，今天就归你惦记。",
  luckyBtn    : "开始抽奖",
  luckyAgain  : "再抽一次",
  luckyWord   : "你的幸运猫猫是"
};
```

封面的「17 只 · 19 张照片」和名录的「17 只」都是自动算的。

### 2. 每只猫

```js
/* 04 */ { name:"奶油", en:"NAI YOU", imgs:["assets/c04.jpg"], ar:0.750,
  note:"黑白配色，两条前腿是白的，正对着镜头走过来。" },
```

| 字段 | 说明 |
|---|---|
| `name` | 名字，必填 |
| `en` | 拼音，显示在名字下面 |
| `imgs` | 照片数组。**放两张，页面会出现「另一张」按钮** |
| `ar` | 宽高比 = 宽 ÷ 高。竖拍约 `0.75`，横拍约 `1.33`，方图 `1` |
| `ars` | 可选。两张照片比例不同时用，例如 `ars:[1.335,0.750]` |
| `note` | 手记，只写照片里看得见的东西 |

这一版已经去掉品种 / 习性 / 常驻地三个字段，每页只留照片、名字和一句话手记。想加回别的字段，照 `note` 的写法在猫页模板里加一行就行。

### 3. 加一只猫

在 `CATS` 数组里照格式复制一段。只用做两件事：

1. 把照片压到宽 900px 左右、JPEG 质量 80，放进 `assets/`
2. 改 `name`、`en`、`imgs`、`ar`

加完之后，封面数字、名录格数、「第几只」都会自动更新，不用手改别的。名录末尾的「＋ 待加入」格子会自动跟着挪。

页面位置也全是算出来的（`INDEX_AT`、`CAT_START`、`MORE_AT`、`OUTRO_AT`、`LUCKY_AT`、`GUIDE1_AT`、`GUIDE2_AT`），所以加猫减猫之后，名录跳转、抽奖跳转都不会错位。

### 4. 幸运抽奖

抽奖逻辑在脚本里「交互：幸运抽奖」那一段。抽到之后有两个链接：

- **分享给朋友**：把文案复制到剪贴板，例如「我在《广大猫猫图鉴》抽到的幸运猫猫是「黑桃」🐾 你也来抽一只：网址」，顶部弹一条提示。
- **去看看 XX**：直接跳到那只猫的页面。

微信内置浏览器**不允许网页唤起分享面板**（`navigator.share` 在微信里不存在，硬调还可能崩渲染进程），所以这里走「复制文案 + 提示」，让对方自己粘贴。微信里想转发整页，还是点右上角 `···`。

奖池就是整个 `CATS`，所以**加猫就等于加进奖池**，不用另外维护名单。想排除某只猫，在 `CATS` 里给它加 `noDraw:true` 这样的标记，再在 `drawLucky()` 里筛一下即可（目前没需要，就没写）。

### 5. 两页守则

搜 `const GUIDES`，是一个数组，每项一页：

```js
{
  kicker:'MEOW MEOW GUARDIANS · 01',
  title :'救助总则',
  lead  :'一句话：绝育 ＞ 投喂。',
  foot  :'内容整理自 Meow Meow Guardians 救助守则',
  items :[ { h:'标题', tag:'核心', p:'正文，可以用 <b>加粗</b>' }, ... ]
}
```

改 `items` 就能增删条目；加一整页就往数组里再加一项。

### 6. 只有名字、还没有照片

`imgs: []` 就行，页面显示虚线相框加猫脸图标、写「照片待补」，目录里显示「待补」。

现在的「秃秃」就是这样。

## 二、这一版做了什么

**翻页**

- 手机：左右滑动 / **点屏幕左右两侧各 24%**（页面边缘有半透明的翻页键作提示）/ 点底部「上一只 · 下一只」/ 点底部刻度
- 电脑：两侧圆形箭头、点屏幕任意位置（左边 25% 上一只，其余下一只）、滚轮、键盘 `← →` `空格` `Home` `End`

用 `transform` 位移实现，不依赖浏览器横向滚动，所以鼠标点击一定能用。

手机上点中间不会翻页，只有左右两侧的窄条会——避免点照片的时候误翻。名录、抽奖、两页守则有内部滚动或按钮，整体关掉了点击翻页（滚轮也不接管），只能用底部导航或滑动。

**「待加入」位**

每只猫之后有一页虚线相框，写「下一只，等你来认领」，配合尾页那句「知道猫猫信息的宝子，欢迎留下微信号」。目录末尾也有一个「＋ 待加入」格子，点进去就是这一页。

**动画**

- 内容元素依次上浮淡入，照片从轻微放大淡入
- 封面线描猫进入时「画」出来，眼睛会眨
- 翻页 0.6 秒阻尼缓动，拖拽跟手
- 顶部进度条随页推进

**流畅度**

页面多了以后翻页会慢慢变卡，这一版专门处理了：

- 目录改用 240px 缩略图，原来是 17 张 900px 大图，体积从 3 MB 降到 310 KB
- 同一时间只渲染当前页和前后各一页，其余页面不参与绘制
- 相邻页的图提前解码，切过去不用等
- 赞赏码页的图固定了尺寸，不会出现"先空一块再撑开"的跳动
- 尾页入场改成纯淡入，文字不再逐帧重画

**版面**

- 封面不用猫照片，用手绘线描猫
- 每只猫是一张档案卡：白边照片微微倾斜、巨大编号水印、字段表
- 手机上下排布，电脑左右分栏（≥820px）；平板竖屏和 1920 大屏各有单独一档

## 三、发布到 GitHub Pages

1. 新建 public 仓库，比如 `gzhu-cats`
2. **Add file → Upload files**，把 `index.html` 和整个 `assets` 文件夹拖进去，Commit
3. **Settings → Pages** → Source 选 *Deploy from a branch* → Branch 选 `main`、目录选 `/ (root)` → Save
4. 等 1～2 分钟：

```
https://你的用户名.github.io/gzhu-cats/
```

> `github.io` 在国内偶尔慢或打不开。微信里加载不出来，就把同一个文件夹拖到 Vercel 或 Cloudflare Pages，免费、绑定快。
